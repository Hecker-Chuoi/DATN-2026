Đánh đổiMạnh nhất, nhưng tốn nhất ở phía server

Realtime "miễn phí" cho frontend, đắt cho backend

Ưu

  • Frontend chỉ khai báo dữ liệu, realtime tự có ở mọi màn hình.
  • Không phải viết tay "sự kiện X thì cập nhật màn Y".
  • Logic nghiệp vụ vẫn ở server (ghi đi qua LunaServer).

Nhược

  • Phải xây một CSDL/cache trung gian biết theo dõi phụ thuộc truy vấn.
  • Phi chuẩn hoá dữ liệu thành bảng index: "a write to a single object value can cascade to many physical indices".
  • Gắn chặt binlog nên nâng cấp DB khó.
  • Hầu như không dùng read replica.
