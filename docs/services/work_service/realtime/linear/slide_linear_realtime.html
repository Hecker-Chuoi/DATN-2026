Offline

Transaction nằm trong IndexedDB, mở lại thì gửi tiếp. Lưu ý: "some transactions are not idempotent".

Undo/Redo

Mỗi transaction có undoTransaction(). Undo là một transaction mới đi đúng luồng.

Loại: Creation · Updating · Deletion · Archival · Unarchive · Local.

Áp tuần tự dưới updateLock.runExclusive. Delta có thể khác transaction gốc vì server thêm hiệu ứng phụ, và client luôn theo delta.

Không sao chép, nhưng mượn 4 ý tưởng

Vì sao không làm như Linear

  • Phải viết ORM phía client, IndexedDB và migrate schema.
  • Work-service có nhiều rule phía server (workflow guard, WIP, cascade sprint/subtask, hierarchy), nên optimistic sẽ phải rollback liên tục.
  • Logic quyền bị nhân đôi giữa server và client.
  • Vượt phạm vi một đồ án.

4 ý tưởng nên mượn

  1. seq tăng dần theo project để phát hiện hụt rồi refetch.
  2. Phát lại cho cả người gây ra, kèm clientMutationId theo tab.
  3. Sync group tương đương /topic/projects/{id}, kiểm quyền khi subscribe.
  4. LWW theo trường + version để chống ghi đè.
